# Labrador

Labrador is a realtime multiplayer prompting product: Codex-like AI work sessions
with Google Docs-style collaboration.

Read `AGENTS.md` and the files in `brain/` before changing implementation details.

## Current Layout

- `src/frontend`: Next.js App Router app for Vercel.
- `src/backend`: future Rust realtime WebSocket service for Railway.
- `brain`: normative implementation instructions for coding agents.
