# Labrador Brain

`brain/` is Labrador's operating system for product and engineering agents. It is not
public marketing documentation. It exists so agents can write fast, coherent code under a
tight deadline without losing the product thesis.

## Folder Map

- `product/`: product thesis, PRD, PRFAQ, product model, philosophy, and customer promise.
- `engineering/`: architecture, protocol, data, security, AI, collaboration, glossary, and agent coding rules.
- `design/`: interface rules and visual reference material.
- `operations/`: speed, testing, delivery mode, CI/CD, and execution discipline.

## Required Reading

Agents MUST start with `../AGENTS.md`, then read the documents relevant to the change.

Implementation-critical docs:

- `engineering/ARCHITECTURE.md`
- `engineering/SECURITY.md`
- `engineering/PROTOCOL.md`
- `engineering/DATA.md`
- `operations/SPEED.md`
- `operations/OPERATING_MODE.md`

Product-critical docs:

- `product/PRD.md`
- `product/PRFAQ.md`
- `product/PRODUCT.md`
- `design/DESIGN.md`
- `design/REFERENCE.md`

## Operating Principle

Labrador MUST move extremely fast without normalizing sloppy code. The correct default is
small, explicit, well-tested implementation that preserves future velocity.
